# 승강기 허브 (Elevator Hub)

승강기 설계·설치·유지보수 계산기 — GitHub Pages용 정적 사이트.

**사이트 주소:** https://motorwindinghub.github.io/elevator-hub/

## 사이트 소개

한국어 승강기 계산 허브로, 승강기 설계자와 설치·유지보수 기술자를 위한 무료 온라인 계산기를 제공합니다. 한국 기준(KS B ISO 4190, 승강기 안전기준)과 한국 전원 조건(380V 3상 / 220V 단상, 60Hz)을 따릅니다. 순수 HTML5, CSS3, 바닐라 JavaScript로 만들었으며 프레임워크, 빌드 단계, 백엔드가 없습니다.

## 계산기 (모두 브라우저에서 동작)

1. **승강기 용량·정원 계산기** — 정격 적재하중에서 정원, 최소 카 면적, 표준 카 치수, 출입구 폭을 계산합니다. KS B ISO 4190 기준 대표값입니다.
2. **승강로 치수 계산기** — 카 치수와 정격 속도에서 승강로 최소 폭·깊이, 피트 깊이, 최상층 높이(오버헤드)를 계산합니다.
3. **소요 동력 계산기** — 정격하중, 속도, 카운터웨이트 균형율, 권상기 효율에서 불균형 하중과 소요 동력을 구하고 전동기 용량, 정격 전류, 권장 MCCB를 선정합니다.
4. **교통량·평균 대기시간 계산기** — 층수, 층고, 속도, 정원, 대수에서 Barney 식 기반 왕복시간(RTT), 5분 수송인원, 운행 간격, 평균 대기시간을 계산합니다.
5. **유지보수 비용 계산기** — 대수, 속도, 설치 연수에서 월·연간 유지보수료, 정기검사비, 부품교체 적립금을 계산합니다.

또한 정격하중별 정원·카 치수·승강로 치수·소요동력 표준값 표, 승강기 설치·점검·고장 대처에 관한 6편의 실무 가이드, 자주 묻는 질문, 소개 및 면책 조항을 포함합니다.

## GitHub Pages 배포 방법

1. GitHub 사용자 **motorwindinghub** 아래에 **motorwindinghub.github.io** 저장소를 사용합니다.
2. 이 폴더의 모든 파일을 저장소의 `elevator-hub/` 폴더에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → branch `main`, folder `/ (root)`** 로 설정합니다.
4. 몇 분 뒤 **https://motorwindinghub.github.io/elevator-hub/** 에서 사이트가 열립니다.

## 로컬 미리보기

```bash
python3 -m http.server 8000

```

## 면책 조항

모든 계산 결과는 참고용 추정치입니다. 실제 설계·시공·검사에는 제조사의 사양서, 승강기 안전기준, 전기설비기술기준(KEC) 및 관련 법령을 반드시 확인하고, 자격을 갖춘 승강기 기술자 또는 검사기관의 판단을 따르십시오. 본 사이트의 계산을 근거로 수행한 작업에 대해 승강기 허브는 책임을 지지 않습니다.
